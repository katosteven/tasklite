# Tasksite
.venv/bin/python serve.py
A small, security-first Django 5 task manager. Functional rewrite of the
`taskManager` legacy app with all OWASP findings closed at the framework level.

## Features

- User registration, login, logout
- Password change + email-based password reset
- Projects with owner / members and per-project access control
- Tasks (create, edit, complete, delete) and threaded notes
- File attachments with safe upload + access-controlled download
- Full-text-style search across the user's projects and tasks
- Personal dashboard

## Security baseline

- `SECRET_KEY`, `DEBUG`, `ALLOWED_HOSTS` driven by `.env`
- PBKDF2 password hashing (Django default)
- Session + CSRF cookies: `HttpOnly`, `SameSite=Strict`, `Secure` when not in DEBUG
- Strict Content-Security-Policy (no `unsafe-inline`, all directives explicit)
- WhiteNoise serves static assets through the middleware stack so CSP/CTO/HSTS apply
- All views are `@login_required`; project/task/note/file access is filtered
  to objects the requesting user owns or is a member of
- File uploads use Django's storage layer (no `os.system`, no raw SQL)
- All forms are CSRF-protected; the auth flow is Django's built-in views

## Quick start

```bash
python3.12 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env       # then edit SECRET_KEY
python manage.py migrate
python manage.py seed      # creates demo users / project / task
python manage.py runserver
